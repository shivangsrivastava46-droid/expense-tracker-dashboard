# 💰 Expense Tracker Dashboard

A modern and interactive Expense Tracker Dashboard built with React. This application helps users manage their expenses, track spending against a monthly budget, analyze spending patterns by category, and visualize expense distribution through charts.

---

## 🚀 Features

### Expense Management
- Add new expenses
- Edit existing expenses
- Delete expenses
- Category-based expense organization

### Budget Tracking
- Set a monthly budget
- View total expenses
- Monitor remaining budget in real time

### Analytics
- Category-wise expense summary
- Expense distribution Pie Chart
- Visual spending insights

### User Experience
- Personalized greeting with saved username
- Category filtering
- Modern dashboard UI
- Data persistence using Local Storage
- Responsive design

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/shivangsrivastava46-droid/expense-tracker-dashboard.git
```

Navigate into the project directory:

```bash
cd expense-tracker-dashboard
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
